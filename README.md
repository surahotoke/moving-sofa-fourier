# moving-sofa-fourier

動くソファ問題(Moving Sofa Problem)で、ハマーズリーのソファの動きを三角関数で少しずつ変形し、面積が最大になる動きを数値で探すスクリプトです。

解説記事:[受話器型ソファの回り方をフーリエ級数でいじったら、ガーバーのソファまで届いた話](https://zenn.dev/surahotoke/articles/ab567886959919)

## 考え方

ソファを止めて見ると、廊下がソファの周りを回りながら通り過ぎていきます。廊下の曲がり具合を φ(0°〜90°)、曲がりの真ん中からのずれを θ = φ − 45° とします。

廊下の内側のかど(L 字の内側の頂点。以下「かど」)の位置を、ソファ上の点 O からの距離 y と、向きのずれ δ で表します。

```
c(φ) = y(φ) · (cos(2φ + δ(φ)), −sin(2φ + δ(φ)))
y(φ) = r0 + Σ a_k cos(2kθ)      … O からかどまでの距離
δ(φ) =      Σ b_k sin(2kθ)      … 向きのずれ(ラジアン)
```

y = 2/π、δ = 0 のとき、かどは O の周りを半径 2/π で回り、これがハマーズリーの動きです。ソファは「動いていく廊下すべての共通部分」として求めます。

| 係数 | 形 | 面積 |
| --- | --- | --- |
| すべて 0(r0 = 0) | 半円 | π/2 ≈ 1.570796 |
| r0 = 2/π のみ | ハマーズリーのソファ | π/2 + 2/π ≈ 2.207416 |
| 距離と角度を4項ずつ | ガーバーのソファに接近 | 2.219527 |
| 距離と角度を8項ずつ | ガーバーのソファに接近 | 2.219531 |
| 参考:ガーバーのソファ | | 2.219532 |

## 必要なもの

```bash
pip install numpy scipy shapely matplotlib
```

## ファイル

- `moving_sofa_fourier.py`:係数を最適化して面積を出すスクリプト
- `draw_sofa.py`:係数からソファの形を描いて PNG に保存するスクリプト(`moving_sofa_fourier.py` を読み込むので、同じフォルダで実行してください)

## 使い方

### 最適化

```bash
python3 moving_sofa_fourier.py --mode both --K 4
```

| オプション | 説明 |
| --- | --- |
| `--mode both` | 距離と角度の両方を動かす(既定) |
| `--mode y` | 距離だけを動かす(δ = 0) |
| `--mode delta` | 角度だけを動かす(y = 2/π) |
| `--K N` | 項数の上限(既定 3)。距離側は r0 を含めて K 個、角度側は K 個の係数を使う |

K = 1 から順に項を増やしながら、全部の係数を同時に Powell 法で最適化し、各 K の面積と係数 r0, a, b を表示します。面積は、角度の区切りによる誤差を 2A(2n) − A(n) で補正した値です。

### 描画

`moving_sofa_fourier.py` が表示した係数を、そのまま写して渡せます。次は記事に載せた4項ずつの最良解です。

```bash
python3 draw_sofa.py --r0 0.6579 --a -0.0337 0.0434 -0.0036 --b 0.0157 -0.0802 0.0157 -0.0014
```

```bash
python3 draw_sofa.py --r0 0.6579 --a -0.0337 0.0434 -0.0036 --b 0.0157 -0.0802 0.0157 -0.0014 --phi 15 --out mysofa.png
```

| オプション | 説明 |
| --- | --- |
| `--r0` | 距離の定数項(既定 2/π) |
| `--a` | 距離の係数 a_1 a_2 …(cos 2θ, cos 4θ, …) |
| `--b` | 角度の係数 b_1 b_2 …(sin 2θ, sin 4θ, …) |
| `--phi` | その曲がり具合(度、0〜90)の廊下も重ねて描く |
| `--out` | 保存するファイル名(既定 `sofa.png`) |

何も付けなければハマーズリーのソファを描きます。

## 補足

- `--mode both` と `--mode delta` では、曲がり始めのかどを、ハマーズリーと同じく O の真横に置いています(曲がり始めで δ = 0)。このため b_1 はほかの係数から決まり、自由な係数は1つ少なくなります。
- 廊下の腕は無限の長さの代わりに、長さ 8 で打ち切っています。
